# Panzer War Mod SDK

[English](README.md) | [简体中文](README.zh-CN.md) | **Русский**

Создавайте собственную технику, карты, прицелы, камуфляжи, декали и другой контент для **Panzer War**. Этот проект Unity содержит инструменты для создания модов, необходимые библиотеки и примеры ресурсов.

[Скачать проект](https://github.com/WindyVerse/Panzer-War-Mod-SDK/releases/latest) · [Документация по созданию модов](https://doc.game.windyverse.net/)

## 1. Установите Unity

Установите **Unity 2022.3.62f1** через Unity Hub. Открывайте проект именно в этой версии.

Для сборки модов под Android дополнительно установите **Android Build Support**, включая модули Android SDK & NDK Tools и OpenJDK. Для проверки готового мода также понадобится сама игра.

## 2. Скачайте и откройте проект

1. Перейдите на страницу [последнего релиза](https://github.com/WindyVerse/Panzer-War-Mod-SDK/releases/latest).
2. В разделе Assets скачайте **`Panzer-War-Mod-SDK-sdk-*.zip`** и полностью распакуйте архив.
3. Добавьте распакованную папку **`UnityProject`** в Unity Hub и откройте её в Unity 2022.3.62f1.
4. Дождитесь загрузки пакетов, импорта ресурсов и компиляции скриптов. Первый импорт занимает больше времени, чем последующие запуски.

Сохраните исходное расположение папок `UnityProject` и `Packages` рядом друг с другом. Проект использует относительные пути к `Packages`: если скопировать только `UnityProject`, часть зависимостей будет отсутствовать.

Архив релиза уже содержит настоящие DLL и локальные зависимости, поэтому **Git и Git LFS для него не нужны**. Выбирайте ZIP с названием проекта, а не автоматически созданный GitHub архив **Source code (zip)**: в нём вместо двоичных файлов могут оказаться указатели LFS.

## 3. Соберите первый мод

Сначала соберите готовый шаблон техники, не изменяя его ресурсы. Все пути, начинающиеся с `Assets/`, ниже указаны относительно папки `UnityProject`.

1. Откройте **File → Build Settings**. Для мода под Windows выберите **PC, Mac & Linux Standalone**, платформу Windows и архитектуру x86_64; при необходимости переключите платформу. Для Android выберите Android и переключите платформу.
2. В окне Project выберите `Assets/ModManager/BuildPipline-Template-Vehicle.asset`.
3. В Inspector нажмите **Build Linked Objects to AssetBundle** и дождитесь завершения сборки ресурсов.
4. Выберите связанный с этой конфигурацией пакет мода: `Assets/ModManager/Template-Blank-Vehicle.asset`.
5. Нажмите **Package Mod Now**. После упаковки редактор откроет папку с результатом.
6. Установите полученный файл `.modpack` в игру по [инструкции по установке модов](https://doc.game.windyverse.net/manual/gameplay/64310317e9947d97.html), затем проверьте его в ангаре и в бою.

Результат сборки шаблона техники для Windows находится в папке:

```text
UnityProject/Build/Mod-Package/StandaloneWindows64/Template-Blank-Vehicle/
```

**Для каждой целевой платформы нужна отдельная сборка.** После изменения ресурсов или переключения платформы заново соберите связанные ресурсы, а затем упакуйте мод. Пакет для Windows нельзя использовать как пакет для Android.

Для проверки шаблона карты используйте `BuildPipline-Template-Blank.asset` и связанный пакет `Template-Blank-Scene.asset` в той же папке `Assets/ModManager`.

## 4. Создайте собственный контент

Полный процесс создания и публикации модов описан в [документации](https://doc.game.windyverse.net/). Начните с подходящего примера:

| Тип контента | Папка с примерами |
| --- | --- |
| Техника | `Assets/Template-Vehicle` |
| Карты | `Assets/Template-Scene` |
| Прицелы | `Assets/Template-UserSight` |
| Камуфляжи | `Assets/Template-Camo` |
| Декали | `Assets/Template-Decal` |
| Голосовые пакеты | `Assets/Template-VoicePack` |

Храните собственные ресурсы в отдельной папке внутри `Assets`. Создайте свой пакет мода и конфигурацию сборки по образцу примеров, задайте уникальные идентификаторы мода и перед публикацией укажите название, автора, описание и ссылки на ресурсы. При выпуске обновлений того же мода сохраняйте его идентификаторы.

Путь к игре и необязательные папки для автоматического копирования готовых пакетов задаются в инструментах настройки редактора. Личные настройки сохраняются в `UnityProject/Assets/EditorStorage.json`; передавать их другим авторам не требуется.

В папке `Tutorials` сохранены старые справочные материалы. Некоторые снимки экрана, ссылки для скачивания и указанные там версии Unity устарели. Для установки текущего проекта используйте этот README, а для дальнейшей работы — сайт документации.

## Получение проекта через Git

Установите Git и Git LFS, затем выполните:

```bash
git lfs install
git clone https://github.com/WindyVerse/Panzer-War-Mod-SDK.git
cd Panzer-War-Mod-SDK
git lfs pull
```

После этого откройте `UnityProject` через Unity Hub. DLL и другие двоичные ресурсы хранятся в **Git LFS**. Перед запуском Unity дождитесь завершения их загрузки.

## Решение проблем

| Проблема | Что проверить |
| --- | --- |
| Неверный формат DLL, отсутствует плагин или вместо DLL находится маленький текстовый файл | Для копии из Git выполните `git lfs pull`. Если скачивали ZIP, используйте архив проекта из релиза, а не Source code (zip). |
| Не найдены локальные пакеты | Сохраните всю распакованную папку и исходное взаимное расположение `UnityProject` и `Packages`. |
| При упаковке не найден кэш сборки | Сначала соберите связанные ресурсы конфигурации для выбранной платформы, затем упакуйте мод. |
| Игра не загружает мод | Проверьте соответствие платформы пакета платформе игры и выполните действия из инструкции по установке выше. |
| Ошибки при первом открытии проекта | Убедитесь, что используется Unity 2022.3.62f1, дождитесь окончания импорта и проверьте первую относящуюся к проблеме ошибку в Console. |

Если проблему решить не удалось, [создайте обращение](https://github.com/WindyVerse/Panzer-War-Mod-SDK/issues) и укажите версию релиза SDK, версию Unity, целевую платформу и соответствующую ошибку из Console.

## Обновление SDK

Сделайте резервную копию своей работы и распакуйте новый релиз в **новую папку**. Перенесите собственные ресурсы вместе с файлами `.meta`, пакетами модов и конфигурациями сборки. Сохраните существующие ссылки на ресурсы и идентификаторы модов. При необходимости заново задайте личные настройки, затем пересоберите и проверьте моды. Не заменяйте папку `Packages` новой версии файлами из старого SDK.
